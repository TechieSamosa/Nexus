# Aditya Khamitkar — Portfolio

> **Engineering intelligence from the systems layer upward.**

This repository contains the source code for my personal engineering portfolio. It is designed to be a "Mission Control" interface, reflecting my focus on AI Infrastructure, Machine Learning Systems, and Distributed Computing.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Architecture & Design

The application is built with a strong emphasis on performance, typography, and atmosphere. The terminal environment is entirely custom-built and heavily state-managed to avoid unnecessary re-renders. All animations are strictly optimized using `framer-motion` `whileInView` and hardware-accelerated CSS properties to ensure a perfect Lighthouse score and 60 FPS performance.

## Running Locally

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm run dev
   ```

3. **View the Application**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
